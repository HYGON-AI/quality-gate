# v2.0.12 — Remove Semgrep from PR checks

- Remove Semgrep from reusable workflow, CLI checks and executor dispatch.
- Code security now runs only Gitleaks. Its findings remain redacted advisories;
  missing images/reports and execution failures still invalidate that check.
- Preserve Code compliance, Code quality and All required checks names/behavior.
- No static security analysis of Python/JS/TS is provided by this release.
  This is a deliberate coverage reduction, not a fix for the Semgrep parser.
- No Semgrep image is required by current PR jobs. Historical diagnostic helpers
  and fixtures are retained but cannot be selected via the PR gate CLI.
- Keep existing images for older pinned gate versions and rollback.

Release only after independent review and successful CI/regressions; stable is
not changed by this PR. No changes to target repository source are required.
