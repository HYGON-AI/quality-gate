# v2.0.10 — Analysis scaling and executable workflow scope

## Fixes

- Avoid repeatedly rebuilding candidate values that are the identical immutable
  list in both branch snapshots. Changed values still merge with typed
  deduplication and complete incremental origins. Each join stays budgeted;
  work/time, candidate count, string size and expression depth limits remain
  enabled. This targets Sglang `server_args.py` exhausting the work budget.
- Recognize only direct `.github/workflows/*.yml` and `*.yaml` as executable
  workflows. The standalone Actionlint driver and native checker agree on this
  boundary. Nested CI selector maps no longer receive workflow-schema or
  Action-reference diagnostics; ordinary YAML syntax and duplicate-key checks
  remain enabled. This targets the vLLM `hcu-test-map.yaml` false positive.
