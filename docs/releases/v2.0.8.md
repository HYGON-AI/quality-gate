# v2.0.8 — PR gate reliability

## Fixes

- Deduplicate Python branch/loop candidate values while retaining all source origins. Bound expression growth, work and time; report budget exhaustion as Invalid Scan, not a clean scan. Fixes Megatron-LM-das #117 runaway memory.
- Recognize Git mode 160000 as a submodule commit reference, not a blob. Preserve path checks and `.gitmodules` scanning. Fixes pytorch-das #20.
- Ignore textconv and external diff drivers and force textual Git hunks, so `.gitattributes -diff` cannot hide newly introduced findings.
- Run mandatory Ruff checks in isolated/no-noqa mode. Caller per-file ignores and inline suppressions cannot disable E9/F63/F7/F82.
- Preserve scanner exit codes and safe operational classifications for absent/malformed reports, missing images, ENOSPC, permissions and timeouts. Arbitrary raw scanner output is withheld. Clean up only the invocation's container on tool timeout.
- Add phase timing, Python version reporting and native process resource limits. Prefer existing Python 3.12; never replace system Python or download an interpreter during PR scans.
- Add explicitly approved `OpenMDW-1.1` to SPDX admission. Original notices still cannot be removed/replaced; this is not a claim of legal equivalence to MIT. Other license expressions retain existing review policy.

## Unchanged

Four job names and `Checks / All required checks`; secret and sensitive-word advisories; C/C++ exclusion from Semgrep; no Lizard/style checks; immutable scanner image references; offline PR scans; centralized policy trust.
