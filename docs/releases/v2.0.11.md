# v2.0.11 — Deferred Python binding candidate overflow

## Fix

Target the candidate-count failure in composable_kernel-das PR #10. Conditional
kernel-name construction can exceed 256 candidates without feeding a recognized
runtime output. Retain an explicit overflow marker for these assignments and
branch joins instead of invalidating the whole scan immediately. Overwriting a
binding with a known value restores ordinary analysis.

Reading an overflow marker at a print, log, exception or other recognized output
still fails closed with Invalid Scan. No candidates are silently truncated;
independent output findings and incremental origins remain checked. Candidate,
work, time, string-size and depth limits remain enabled. No scanner image,
license policy, allowlist, runner setting or workflow scope changes are included.

branches/loops, overwrites, output sinks and unchanged non-candidate budgets.

tests and the Python 3.9/3.11/3.12 CI matrix before release.
