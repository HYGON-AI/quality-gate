- Candidate/string/work exhaustion and empty-message `MemoryError` explicitly fail. The old orchestrator could replace `MemoryError` with an empty status detail and accidentally return Passed; this is covered separately.
- `ruff.toml` per-file F823 ignores, inline `noqa`, and `.gitattributes -diff` cannot hide the synthetic new F823 defect. Textconv suppression is separately unit tested.
- Unknown licenses still block; replacing an original OpenMDW notice with MIT still blocks.
- Missing/malformed reports, ENOSPC, missing images and tool timeouts retain safe diagnostics without echoing arbitrary secret/source output. Timeout cleanup targets only the captured container ID.
- Semgrep's network version check was unnecessary with pinned offline images. On nmz4 it took ~45.5s; disabling the version check reduced it to ~1.5s with the same scan results.
