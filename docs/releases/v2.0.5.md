# v2.0.5 — 低噪声摘要与许可证声明保护

## 修复

- 版权/SPDX 声明比较忽略换行、空白及常见注释包装；保护跨行的原权利人名称。
- 识别完整标准 MIT、BSD-3-Clause 正文和 Apache-2.0 声明头；无 SPDX 时不机械要求改头。
- 删除原传统许可证条款或免责声明仍阻断，即使保留 Copyright 或新增 SPDX。
- 修复独立 AmD/XgMi 混合大小写词漏检；保持提示、不阻断，不扩大为任意子串匹配。

## 摘要

- 保留四个 Job/检查名称；无适用文件显示“无需检查”。
- 结论、计数、实际版本及执行 SHA 在前，范围/工具详情折叠。
- 内置检查使用具体名称，同位置阻断诊断合并展示但保留证据与原始计数。
- 成功措辞：质量门禁通过；是否可合并以仓库保护规则为准。

## 保持不变

- 密钥发现脱敏且仅提示；扫描器执行失败仍是 Invalid Scan。
- 不自动修改上游声明，不推断 H1/H2/H3 或原创归属；未知来源的新文件缺头只提示。
- 完整模板识别有明确范围，不把未知/残缺许可证判为已准入；扫描受配置行数限制。
- `v2.0.4` 及更早标签不变；`stable` 更新到本版本后，原 `@stable` 调用自动使用新版。

## 验证

发布前执行 Linux 原生自测、全部单元回归、启动环境测试、真实扫描器集成及消费仓库测试 PR。
实际运行链接与结果见发布记录；不将“测试存在”当作“测试已通过”。
